Fact Opinion False

Talk together. Is each sentence a fact, an opinion or false?

    Write one fact, one opinion and one false sentence about where you live.

    Read them out. The class decides which is which.

    Ask each other

    • What do you think?
    • Do you agree?
    • Is that true?

    Think aloud

    • I'm not sure, but I think …
    • It depends on …

    Decide

    • That's a fact.
    • That's just an opinion.
    • That's not true. Actually, …
